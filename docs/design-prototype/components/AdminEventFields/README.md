# AdminEventFields

随机事件字段表单：名称、事件组、类别、版本、状态、权重、持续与冷却时间、说明、效果标签。所有修改以 `patch` 事件向外抛出。

**结构**
- 名称（必填）；事件组与类别并排（可选择或新建，类别必填）；版本（必填）与状态（开发中 / 已实装 / 已移除）并排
- 权重（步长 0.05，提示“稀有度：…”）与“持续时间（秒）”并排；“内置冷却（秒）”；“内容说明”四行文本域
- “效果标签”多选，可新建，占位“输入或选择效果标签”

**状态**
- `disabled` 时全部禁用
- 数字清空为 null，事件组清空为 null；标签去空格并过滤空项
- 窄容器（小于 24rem）两列变单列；没有校验错误文案

**Token**：`space-3`；控件全宽，不使用自定义颜色。

**无障碍**
- UFormField 关联 label；效果标签有 `aria-label`
- 必填字段带 `required`
