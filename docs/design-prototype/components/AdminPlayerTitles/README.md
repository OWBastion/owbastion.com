# AdminPlayerTitles

展示玩家名下的全局称号和地图称号，支持回收、手动授予，以及修复佩戴选择。

**结构**
- `section`（“称号”）：组标题“全局称号”，其后按地图分组（组名是地图名，未知为“未知地图”）。称号卡片自适应网格，最小宽 15rem。
- 卡片：称号名（已佩戴追加 “★”，`accent` 色）；元信息“槽位或分类 · 来源 · 授予时间”；有效称号显示“回收”按钮（`error` ghost，不换行），已回收称号显示“已回收”`error` 徽标且无按钮。
- 槽位：开拓者 / 征服者 / 主宰；来源：历史迁移 / 截图核对 / 人工发放 / 自动获得。
- 对话框“手动授予称号”（选全局或地图称号、可选“发放原因”，“确认授予”）与“修复佩戴称号”（最多选 10 个，“保存佩戴选择”）。

**状态**
- 已回收卡片透明度 0.55，不再提供持久的“撤销回收”；需要恢复时走“手动授予称号”。回收为乐观更新，失败回滚。
- 空：“暂无全局称号。”“还没有称号。”
- 回收成功 toast “已回收{称号}”，带“撤销”动作（仅此刻的即时撤销），保留 8 秒；失败“无法回收称号”。
- 超过 10 个：`role="alert"` “最多选择 10 个称号。”

**无障碍**：各分组有 `aria-labelledby` 或 `aria-label`；已选区 `aria-live="polite"`；复选框由 `label` 包裹。
