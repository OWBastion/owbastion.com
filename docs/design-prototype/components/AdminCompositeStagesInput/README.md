# AdminCompositeStagesInput

编辑复合空间配置的“组合规则”（选择数量、首阶段与后续阶段选择）以及各原子阶段（阶段 ID、初始阶段检测、阶段点位）。

**结构**
- 组合规则：选择数量（2 到 16）、首阶段选择（检测地图初始阶段 / 随机选择）、回退阶段、后续阶段选择（随机选择且不重复 / 按阶段 ID 升序循环）
- 阶段列表（`aria-label="原子阶段"`）：每个阶段一个 fieldset，含阶段 ID、“移除阶段”、检测位置 X/Y/Z 与检测半径、阶段点位输入
- 末尾“添加阶段”描边按钮，回退阶段带“回退阶段”徽章

**状态**
- `disabled` 时全部禁用；阶段数不超过 2 时“移除阶段”禁用；达到 16 个隐藏“添加阶段”；新阶段 ID 自动为 stage-N
- 循环选择提示：“阶段按 ID 升序衔接，最后一个阶段会回到第一个。”
- 错误以 `role="alert"` 展示，如“请选择一个已存在的回退阶段。”“阶段 ID 重复。”“检测半径必须大于 0。”

**Token**：`line`、`radius-control`；legend 0.9375rem/600；窄容器阶段行单列。

**无障碍**
- fieldset 加 legend，输入有 aria-label（如“阶段 ID stage-1”“stage-1 检测半径”）
- 检测位置 `role="group"`，错误 `role="alert"`
