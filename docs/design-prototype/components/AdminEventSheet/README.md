# AdminEventSheet

右侧滑出面板，用于查看和编辑单个随机事件（概率说明、字段表单、上一条/下一条、归档），或新建事件。

**结构**
- 标题：新建时“新建事件”，编辑时为事件名；无可见描述（读屏用标题）
- 编辑模式顶部概率区：大号概率、“已保存 x%”、说明“平均每 N 次事件抽取出现 1 次”，下接 AdminEventFields
- 编辑页脚：上一条/下一条图标按钮、“改动已进入页面顶部的草稿，统一保存”或“没有修改”、“归档”、“完成”
- 新建页脚：“创建事件”和“取消”

**状态**
- 不在候选池时概率说明为“不在候选池：只有已实装且版本未挂起的事件参与抽取”
- 点击“归档”后变为“确认归档”（error soft）；关闭面板重置确认
- `creating` 时“创建事件”loading；`values` 为空时不渲染主体

**Token**：`accent`、`accent-surface`、`muted`、`radius-card`；概率用 `type-headline` 尺寸、字重 700。

**无障碍**
- 概率区 `aria-live="polite"`
- 上一条/下一条图标按钮有 aria-label；面板语义由 USlideover 提供
