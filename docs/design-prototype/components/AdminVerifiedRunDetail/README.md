# AdminVerifiedRunDetail

展示一条已核验通关记录：事实、来源提交、经验规则与地图档案、更正历史、对局码冲突和状态记录，并触发更正、作废、冲突处理。

**分区**（每区 `section` 加 `aria-labelledby`，标题行右侧放徽章或计数）
- “通关记录”（有效 `success` / 已作废 `warning`）：玩家、地图、难度、对局码（等宽）、通关用时“N 分 M 秒”、死亡 / 跳过、接受来源（自动通过 / 人工核对）、接受时间、游戏版本、地图版本（经典版 / 默认）；已作废时追加作废时间、作废者、理由。操作：“更正记录事实”“作废通关记录”或“恢复通关记录”。
- “来源提交”：提交编号、识别状态、识别次数；“查看来源提交”。
- “经验规则与地图档案”：规则版本、基础经验、各项加成、本局经验；累计经验、有效记录、最高难度等。
- “事实更正历史”（有记录才显示）、“对局码冲突”（“处理冲突提交”“保留原记录”“作废原记录”）、“状态记录”（已接受 / 已作废 / 已恢复）。

**状态**
- 缺失值统一显示“暂无记录”（`quiet`）。无冲突时标题“暂无冲突记录”。
- `actionLoading`：所有操作按钮禁用并 `aria-busy`；原记录已作废时“作废原记录”也禁用。
- 窄于 23.99rem：分栏改单列，按钮铺满，最小高度 2.75rem。
