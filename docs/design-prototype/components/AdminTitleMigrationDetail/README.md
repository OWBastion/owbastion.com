# AdminTitleMigrationDetail

历史称号迁移的详情面板：显示所选历史持有者，搜索目标玩家帐号，并逐项或批量把称号关联到玩家，或撤销关联。

**结构**
- 头部：42px 头像、“历史持有者”小标题、持有者名、“N 项称号 · M 项未关联”
- 右侧：“选择目标玩家帐号”下拉（搜索占位“输入 BattleTag 或帐号名”，选项“夜航#1234”）与“关联全部未关联项”按钮
- 表格列：分类、称号（含地图名）、状态（未关联 / 已关联 / 已撤销）、操作（“关联”“撤销”）
- 分页：“共 N 项 · 第 P 页”加页码

**状态**
- 未选择持有者：只保留一句“从左侧选择历史持有者”
- 玩家搜索：“正在搜索玩家…”“未找到可关联玩家”“已显示 n / total 位玩家”加“加载更多玩家”；错误用 `danger` 并 `role="alert"`
- 表空“暂无称号记录。”；“关联”需已选玩家且非保存中；loading 或 saving 时表格 loading、选择器禁用

**Token**：`accent`、`on-accent`、`danger`、`quiet`、`space-1..8`；窄容器（小于 24rem）纵向、控件全宽。

**无障碍**
- 头像 `aria-hidden`；下拉 `aria-label` 为“选择目标玩家帐号”
- 玩家状态 `role="status"`/`role="alert"`
