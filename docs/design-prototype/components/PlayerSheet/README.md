排行榜点击某位玩家后从右侧滑出的资料面板：排名、地图称号阶梯、通用成就。匿名玩家只显示受限信息。

**使用**：传入 `entry: LeaderboardEntry | null`，用 `v-model:open` 控制；打开时请求该玩家的公开资料。

**结构**
- 头部：3.5rem 圆形头像（首字，`accent` 2px 边框；匿名为「?」，`line-strong` 边框、`quiet` 字）、玩家名（匿名为「匿名玩家」）、已佩戴称号胶囊。
- 统计两格：「地图精通排名 · {score} XP」「成就排名 · {n} 个」，无名次显示「—」。
- 地图区：「地图 · 玩过 {n} / {总数} 张」，主宰 / 征服者 / 开拓者三格汇总，地图行最多 5 行，按钮「展开其余 {n} 张地图」。
- 成就区：「成就 · {n}」，称号胶囊最多 10 个，按钮「展开其余 {n} 个」。
- 匿名：「公开主页」＋「这位玩家关闭了公开主页。名次照常保留，但不显示昵称、成就和地图明细。」

**状态**
- 读取中：`role="status"` 两块骨架；错误：「无法读取玩家」「请稍后重试。」＋「重试」。
- 空：「还没有通关记录」「还没有解锁成就」。
- 地图按 XP 降序，同 XP 按名称排序。

**无障碍**
- 头像 aria-hidden；错误 `role="alert"`；展开为原生按钮；标题与焦点由侧滑面板提供。
