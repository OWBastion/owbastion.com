# AdminEventTable

随机事件管理表：支持多选、列排序、行内暂存编辑（事件组、权重、版本、状态）和概率变化可视化。

**结构**
- 列：复选框、事件、事件组、类别、权重、出现概率、版本、状态；表头吸顶，事件/权重/概率/版本可排序
- 事件名是打开详情的按钮，被改动时附“已改”徽章
- 类别着色：减益 `danger`、增益 `success`、机制 `info`
- 概率列：accent 细条加百分比，变化显示 ▲/▼ 数值（上升 `success`，下降 `danger`）

**状态**
- 选中行 `accent-surface` 背景；非已实装或版本被挂起的行透明度 .6
- 已改字段的输入用 accent 边框和 `accent-surface`，字重 600
- 容器小于 48rem 隐藏类别、版本和概率条；小于 40rem 再隐藏事件组、状态；无空态和加载态文案

**Token**：`line`、`surface`、`accent`、`accent-surface`、`success`、`danger`、`info`、`radius-card`、`radius-pill`。

**无障碍**
- `th` 带 `aria-sort`，排序是按钮
- 复选框和输入均有 aria-label（“选择 狂暴齿轮”“权重”等），变化量含屏幕阅读器文字“上升”“下降”


**未保存修改的表达**（建议稿，预览已按此绘制，代码尚未实现）
