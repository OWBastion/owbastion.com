# AdminAchievementCreateDialog

新建成就挑战（称号规则）的大型表单对话框，含进度型“集齐指定地图”规则和图标设置。

**结构**
- 必填：称号名称、完成条件；选择完成规则（截图条件或集齐指定地图）和状态（草稿、已开放、已下线）
- 进度模式增加统计范围、最低难度、要求地图；状态非已下线时有开始与结束时间，已开放时有计划下线版本
- 折叠区“更多设置”：唯一 key、系列、图标、展示分类、游戏版本、截图规则、提交方式、称号适用范围、地图版本、自定义图标与上传
- 底部“创建挑战”和“取消”

**状态**
- `saving` 时全部输入禁用、提交 loading
- 名称或条件为空，或进度模式下没选地图或模式时，“创建挑战”禁用
- 切到进度模式自动重置为手动提交、全部地图；key 留空自动生成 `CHALLENGE_XXXXXXXX`
- 图标提示：“PNG、JPG 或 WebP，创建挑战后上传，最大 512 KB。”

**Token**：类 `admin-achievement-editor`、`editor-field`；“更多设置”顶部 1px `line`，文字 `muted`。

**无障碍**
- 原生 form 与 `required`
- `details/summary` 原生折叠，图标预览 alt 为“当前成就图标”


**统一布局**（建议稿，预览已按此绘制，代码尚未实现）
- 新建与编辑使用同一顺序：基本信息（名称、完成条件）→ 状态与完成规则 → 时间（开始、结束、计划下线版本）→ 更多设置（截图规则、提交方式、适用范围、游戏版本、图标、展示分类）。
- 同一行的字段顶端对齐，不因相邻字段带说明文字而被拉高；选择框高度与输入框同为 `control-md`。
