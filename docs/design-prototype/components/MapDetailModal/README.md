地图详情弹层：桌面为居中模态框，移动为底部抽屉。显示地图概览、挑战列表、特殊机制与玩家评价面板。

**使用**：传入 `map: Map | null`、`challenges`、`authenticated`，用 `v-model:open` 控制；评价变化时触发 `review-changed`。

**结构**
- 标题为地图名（无地图时「地图详情」），描述「版本 {gameVersion}」。≥ 768px 用 `glass-heavy`、`elevation-3`、最大宽度 max-w-2xl 的模态框；否则用底部抽屉（最大高度 calc(100dvh - 1rem)，含安全区内边距）。
- 「地图概览」＋「{n} 项挑战」；事实：「地图评级」「挑战难度」（缺失显示「暂无记录」）。
- 挑战列表：挑战名＋右侧「难度 · 即将结束」（无则「—」）；开拓者优先，再按 简单 < 一般 < 困难 < 专家 < 传奇 < 地狱，再按名称。
- 「特殊机制」徽标列表（有机制才显示）。
- 底部是 `PlayerReviewPanel`。

**状态**
- 仅在水合后渲染；`map` 为 null 时内容不渲染；挑战为空则不显示列表。
- 动画受 `prefers-reduced-motion` 控制（过渡 1ms）。

**无障碍**
- 概览 section `aria-labelledby="map-overview-title"`；标题、描述、关闭按钮由弹层组件提供。

**建议稿（2026-10）**：线条只出现在同组内的行与行之间，且不叠加。概览的键值行不加分隔线（靠间距）；“挑战”列表自成一节，仅条目之间有一条线，首条不画顶线，避免与上方分隔线重复。
