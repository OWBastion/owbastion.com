# EvidenceViewer

截图查看器，支持适应窗口、原始大小、缩放、拖动平移、双击切换，以及“钉在侧边”。用于查看提交的游戏截图。

**结构**
- 工具栏（`role="toolbar"`，aria-label「截图查看」）：sm 按钮——「适应」「100%」缩小、放大（仅图标）、「钉在侧边」（取代全屏）；右侧缩放比例（`role="status"`，caption，--quiet，tabular-nums）。
- 视口：1px --line 边框、`radius-control`、--surface-raised 底，`tabindex=0`，非全屏时按图片原始宽高比。
- 属性：`src`、`alt`；图片加载失败只触发 `error` 事件，组件内无错误文案。

**交互**
- 键盘：+/= 放大，- 缩小，0 适应，1 原始大小，F 全屏。滚轮缩放（最大 4x，步进 1.25）；放大后可拖动；双击在适应与 100% 间切换。
- 图片未加载时，除全屏外的四个按钮 disabled。
- 缩放过渡 160ms，滚轮与拖动无过渡；`prefers-reduced-motion` 下关闭。

**无障碍**：按钮 aria-label 如「适应窗口（0）」「放大（+）」「退出全屏（F）」；视口 `role="group"`，提示滚轮缩放、拖动平移、双击切换；img `draggable=false`。

**建议稿（2026-10）**：问题是全屏会盖住手动核对的输入框，且只能在小框内操作。
- 去掉全屏。核对页里查看器固定在左栏（`sticky`），表单在右栏，两者同时可见；缩放和拖动在左栏里进行，视口高度跟随可用高度，不再限制 240px。
- 小屏上“钉在侧边”变为可拖动、可缩放的悬浮窗，放在页面边缘，不遮挡正在编辑的字段；窗口位置与缩放比例在同一次审核中保持。
- 不需要“放大—记住字段—缩小—填写”的往返。
