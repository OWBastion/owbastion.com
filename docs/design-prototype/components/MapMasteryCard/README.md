某张地图的玩家精通卡。合并原 `MapRecords`（主页的精通卡网格）、`MapMasteryProfile`（地图详情的“精通记录”）和 `MapProgressOverview`（我的成就里的地图进度卡）。三者都是“这张地图上我做到了什么”，字段重叠：地图名、最高难度、最快用时、最少死亡、精通 XP、已验证通关。

**共同结构**：地图名＋右侧最高难度胶囊（`accent` 字，`accent-surface` 底）；统计行 dl/dt/dd（最快 / 最少死亡 / 精通 XP）；缺失值显示“—”，无记录时整卡不渲染或显示“暂无精通记录”。

**变体**
- `record`（原 MapRecords）：整卡是链接，打开地图详情；只显示统计行；`auto-fill` 网格，最小列宽 18rem；按精通 XP 降序；只含默认玩法版本且已验证通关数大于 0 的地图。
- `progress`（原 MapProgressOverview）：卡头链接到“我的成就”的地图详情，右侧显示“已获得 x / y”或“已完成”（`success`）；下方为目标清单（✓ 已获得 / ○ 未获得，退役中附“即将结束”）；可选统计行。无挑战显示“暂无地图成就”。
- `detail`（原 MapMasteryProfile）：标题“精通记录”；统计扩展为精通 XP、已验证通关、最高难度、最低死亡、最少跳过、单次最高 XP；下接各难度小卡（难度名＋“{n} 次 · 最快 {时长}”）；再下接 `MasteryRunHistory`。状态：未登录“登录后查看”、读取中三块骨架、读取失败“无法读取精通记录”加重试、无数据“暂无精通记录”。

**状态**：loading、error（含重试）、empty、有数据；窄于 24rem 时统计改单列。

**无障碍**：链接带 `aria-label="查看{地图名}详情"`；列表为 ul/li，统计为 dl；目标 marker `aria-hidden`，附 sr-only“已获得”“未获得”；加载区 `role="status"`。

**合并建议稿（2026-10）**：统计行与卡片外壳只实现一份，三处使用只传不同变体。`MasteryRunHistory` 保持独立。
