# AdminMapAchievementWorkspace

地图称号规则工作区，提供“按规则”和“按地图查看”两个视图，管理地图称号规则、开拓者开放窗口和地图级例外，自行请求 API。

**结构**
- 标题“地图称号规则”加计数（读取中…或“N 条规则”），错误用 error 提示条
- 标签页“按规则”“按地图查看”；规则表列：称号、有效地图、地图例外、展示方式、提交方式、状态、操作
- 地图视图用地图下拉加表格；规则行有“编辑规则”“编辑例外”，单图挑战为“编辑挑战”
- 四个对话框：开放窗口管理、例外编辑、规则表单（“保存规则”“保存例外”）

**状态**
- 加载：表格 loading，标题显示“读取中…”
- 空态：“暂无地图称号规则。”“暂无地图成就。”“暂无可管理的有效地图。”
- 错误：“无法读取地图成就，请稍后重试。”“无法保存地图称号规则，请稍后重试。”
- 状态：草稿、已开放、已下线；提交方式：自动提交、手动提交；开拓者规则适用范围锁定“手动分配修订（限时开放）”

**Token**：`type-headline`、`type-caption`、`space-2..6`、`line`、`radius-control`；表格最小宽 860px，容器窄于 24rem 时堆叠。

**无障碍**
- section 以标题 `aria-labelledby`，标签页和地图选择有 `aria-label`
- 状态由 StatusBadge 文字表达
