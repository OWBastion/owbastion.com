GitHub 风格的过去一年每日通关次数热力图（53 周 × 7 天）。

**使用**：传入 `days` 与可选 `now`；网格由 `buildRunDayGrid` 生成（周、月份标签、总通关数、有记录天数）。

**结构**
- 摘要：「过去一年 {totalRuns} 次通关 · {activeDays} 天有记录」。
- 横向可滚动网格（挂载后滚到最右，即最近一周）：月份标签行、星期标签列（一、三、五）、`table` 网格，每格 0.75rem 方块。
- 页脚：只有图例「少」→「多」，靠右（建议稿：删除“按通关日期统计，同一次通关只计一次，不代表游玩时长。”，该口径体现在摘要和格子提示里即可）。
- 色阶：level-0 `surface-raised`；level-1/2/3 为 `accent` 的 28%/50%/75% 与 `surface` 混合；level-4 `accent`；格子内缩 1px `line` 描边；未来日期透明无描边。

**状态**
- 无数据：「过去一年暂无通关记录」，格子仍按 level-0 渲染。
- 格子提示：「{M}月{D}日 · {n} 次通关」或「{M}月{D}日 · 无记录」。

**无障碍**
- 原生 `table` 加 sr-only caption「过去一年每天的通关次数」；非未来格有 `aria-label`；月份、星期标签与图例 aria-hidden。
