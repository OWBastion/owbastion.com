在个人设置中管理 Passkey：查看、添加，确认后移除。无 props，经门户接口读取与删除。

**结构**
- 头部：标题「Passkey」＋说明＋右侧主按钮「添加 Passkey」（取代原“刷新”按钮，列表在操作后自动更新）。已绑 QQ：「添加后可用 Passkey 一键登录；QQ 群验证仍可作为备用登录方式。」未绑 QQ：「Passkey 用于登录 Portal。未绑定 QQ 时，请保留至少一个 Passkey。」
- 列表：名称、「添加于 {date}」、可选「最近使用 {date}」，右侧「移除」（danger soft）。
- 添加流程（建议稿）：先点「添加 Passkey」，由系统完成创建；成功后新条目出现在列表顶部，进入命名态：输入框（默认「此设备」，占位示例「手机、笔记本」）＋「保存」「稍后」；「稍后」保留默认名称。忙时按钮「正在添加…」。不再有页面常驻的名称输入框。
- 确认块（边框 `line-strong`，底 `surface-raised`）：「确定移除「{name}」？这个设备之后将无法用该 Passkey 登录。」＋「确认移除」「取消」。

**状态**
- 读取中「读取 Passkey…」；空「尚无 Passkey」一行「添加后可用设备解锁方式登录。」
- 错误「无法读取 Passkey，请稍后重试。」「无法移除 Passkey，请稍后重试。」
- 「移除」在 Passkey ≤ 1 且未绑 QQ、保存中或操作忙时禁用。

**无障碍**
- 区块 `aria-labelledby`；加载 `role="status"`；确认块 `role="group"`，`aria-label="确认移除 Passkey"`。

**对齐（建议稿）**：标题栏里说明文字与「添加 Passkey」垂直居中对齐；按钮与输入框同高（`control-md`）。命名态一行内输入框与「保存」「稍后」底边对齐，不让按钮对着标签居中。
