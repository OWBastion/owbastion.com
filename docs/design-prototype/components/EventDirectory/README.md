随机事件目录：搜索、筛选、排序、分组的事件卡片网格，点击卡片打开事件详情（桌面模态框，移动抽屉）。

**使用**：传入 `events: RandomEvent[]`、`authenticated`。

**结构**
- 搜索框（占位「搜索名称、说明、事件组或效果」）；窄屏用「筛选与排序」按钮折叠面板，有条件时显示「筛选与排序 · {n}」。
- 面板：排序（最新版本 / 名称 / 出现概率高到低）、分组（不分组 / 按事件组 / 按版本 / 按类别）、事件组与常见效果筛选芯片、类别与稀有度芯片、版本与状态下拉。
- 结果行：「{n} 项事件」＋有条件时「清除条件」。
- 事件卡：名称（非已实装附警告徽标「开发中」或「已移除」）；元信息为事件组、类别（增益 `success`、减益 `danger`、机制 `info`）、稀有度、版本；描述（3 行截断）；概率条「概率」；「{n} 秒 · 冷却 {n} 秒 · 权重 {n}」；最多 3 个效果标签，溢出显示「+{n}」；评价摘要。
- 详情：出现概率、持续时间、内置冷却、权重、概率统计、效果、开放挑战（空时「暂无开放挑战。」）、评价面板。

**状态**
- 空态：「没有符合条件的事件」＋「清除条件」按钮，无描述。
- 芯片无结果时禁用；窄容器（< 40rem）面板折叠；水合前不渲染浮层。

**无障碍**
- 搜索 `aria-label="搜索事件"`；结果行 `aria-live="polite"`；卡片主按钮为原生 button，`aria-haspopup="dialog"`；芯片行 `role="group"`。
