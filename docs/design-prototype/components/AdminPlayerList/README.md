# AdminPlayerList

后台玩家帐号列表：搜索、状态筛选、分页，每行是进入详情的链接。

**结构**
- `section`（`aria-label` “玩家列表”）：搜索框（占位“搜索战网 ID 或 QQ 标识”，`aria-label` “搜索玩家”）；筛选芯片组“全部 / 正常 / 已封禁”（`aria-pressed`），右侧计数“{total} 位”。
- 每行：玩家名 `strong` 加 “#玩家ID”，右侧标签“待审 N”（强调）或“已封禁”（`warning`）；链接到 `/admin/players/{id}`。
- 超过 20 条出现分页：“上一页”、“N / 总页数”、“下一页”。

**状态**
- 读取中：计数处显示“读取中…”；无数据：“暂无匹配玩家。”
- 错误：“无法读取玩家帐号，请确认当前账号有管理员权限。”
- 当前选中行 `aria-current="page"`，`accent-surface` 底；首页和末页禁用对应翻页按钮；改变搜索或筛选回到第 1 页。

**无障碍**：列表内 ArrowUp / ArrowDown 在链接间移动焦点；行最小高度 2.75rem；减少动效偏好下关闭过渡。
