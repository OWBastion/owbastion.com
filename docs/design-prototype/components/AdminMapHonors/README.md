# AdminMapHonors

按称号分组展示可关联到地图修订的成就与称号：开关、勾选子项，并为开拓者设置开放时间窗口。

**结构**
- 头部提示“打开一个称号，就同时打开它对应的地图挑战和称号规则。”，右侧“套用推荐”小按钮
- 每组一张卡：2.5rem 图标方块、名称加说明、开关
- 开启后缩进显示子项复选框，如“地图挑战 · 通关漓江塔”“称号 · 漓江塔征服者”
- 开拓者开启后显示“开放开始时间”“开放结束时间”（均必填）

**状态**
- 说明文案：“N 项关联”；开拓者“限时：只在开放窗口内可提交”；经典“经典版自定义称号”；不适用时“此修订不是经典版，不适用”（透明度 .55，开关禁用）
- 窗口无效时结束时间报错“需要设置晚于开始时间的结束时间”；首次设置开始时间自动补 +24 小时
- 空态：“这张地图还没有可关联的成就或称号。规则在「成就与称号」模块里维护。”

**Token**：`accent` 与 `accent-surface` 表示已开启；`line`、`surface`、`radius-card`；子区左缩进 4.2rem。

**无障碍**
- 开关 `aria-label` 为称号名
- 图标 `aria-hidden`，窗口错误经 UFormField error，列表语义 `ul/li`
