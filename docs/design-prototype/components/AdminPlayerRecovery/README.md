# AdminPlayerRecovery

核验身份后，为玩家签发一次性 Passkey 恢复链接的对话框。

**结构**：基于 `AdminResponsiveDialog`，标题“签发 Passkey 恢复链接”，说明为 “名称#ID”，尺寸 `sm`。
- 未签发：说明签发后会移除现有 Passkey 并撤销所有 Portal 会话，原 Player Account 的提交、称号和精通记录保留；核验复选框“我已通过独立方式核验玩家身份，并确认恢复到此帐号。”；页脚“签发一次性链接”（`warning` soft）和“取消”。
- 已签发：success 提示“一次性恢复链接已签发”，描述“有效至 {日期时间}”；链接用 `code` 展示（`surface-raised` 底、任意处换行）；页脚“复制恢复链接”和“完成”。

**状态**
- 未勾选核验时签发按钮禁用。
- 签发中：按钮 `loading`，取消和复选框禁用，对话框不可关闭。
- 复制成功后按钮文字变“已复制”，1.6 秒后复位。
- 错误默认文案：“无法签发恢复链接，请稍后重试。”
- 每次打开都重置核验、链接和错误；请求带打开时生成的 `Idempotency-Key`。

**无障碍**：复选框带 `label`；焦点交给对话框管理。
