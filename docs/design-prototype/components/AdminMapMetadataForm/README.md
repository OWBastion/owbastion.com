# AdminMapMetadataForm

管理员编辑单张地图基础资料（名称、难度评级、机制标签、目录版本、封面与背景地址）的表单。传入 `map`，提交时触发 `save`。

**结构**
- 单列表单：地图名称、地图难度评级、特殊机制、目录版本、地图封面地址、地图背景地址
- 地图名称提示“与游戏截图里的地图名保持一致，自动审核按它识别地图。”
- 评级选项：暂无评级、T0 至 T5；机制用标签输入，占位“输入机制标签”
- 底部左对齐“保存地图资料”提交按钮，最小高度 2.75rem

**状态**
- `saving` 为 true 时所有输入禁用，提交按钮 loading 且禁用
- `map` 变化时表单重置为 map 的值；提交时去空格，空地址转 null
- 没有空态和错误态

**Token**：按钮用 `.pressable`；不使用自定义颜色。

**无障碍**
- 原生 form，Enter 可提交
- 必填字段带 `required`，UFormField 关联 label
