# AdminDataTable

后台通用数据表。桌面是带粘性表头的 `UTable`，容器窄于 23.99rem 时切换成卡片式记录列表，并内置排序、分组、列显隐控制。

**结构**
- 根容器：`line` 边框、`radius-card`、`surface` 底；控制条左侧放 `filters` 插槽，右侧是“排序方式”“分组方式”两个选择器和“列”菜单按钮。
- 排序项：“默认顺序”“{列}：升序”“{列}：降序”；仅提供 `sortingOptions` 时表头才可排序。
- 移动端：隐藏桌面筛选，出现“筛选与排序”按钮（`aria-label` “打开筛选与排序”），打开底部抽屉。每条记录显示主字段，其余在“查看详情 / 收起详情”里展开。

**状态**
- `loading`：顶部 2px `accent` 加载条（`role="status"`，“正在加载”）；移动端 3 个高 72px 骨架。
- 空：显示 `empty` 文案，例如“暂无记录。”；移动端无值字段显示“—”。
- 行带链接或动作时，悬停、聚焦、按下有底色渐变；行内按钮和链接不触发整行跳转。

**无障碍**：排序、分组选择器有 `aria-label`；折叠按钮用 `aria-expanded`、`aria-controls`；记录动作菜单 `role="group"`（“记录操作”），按钮“打开更多操作”；列表 `aria-busy`。
