# AdminSubmissionReviewFields

在提交审核中展示 OCRKit 识别出的字段，让管理员逐项核对或修正，并把已核对的值作为字段校正输出。外层是 `AdminSignalPanel`（标题“识别核对”，不显示内部名 OCRKit）。

**结构**
- 汇总行（`role="status"`，字重 600）：“N 项全部一致”；“N 项一致，M 项待你确认”（`warning` 色）；“{字段} 无法识别，请修正后再通过”（`danger` 色）。
- 字段芯片列表（“识别字段”）：状态图标、标签、值（最宽 12rem 截断）。主字段：地图、难度、玩家名称、通关标记、地图版本、模式、左侧成就面板；“更多字段（N）”展开游戏版本、对局码、通关用时（秒）、死亡次数、跳过次数。
- 展开的编辑器（`role="group"`，“{标签}核对”）：“识别：{文本}”、置信度、字段状态；按钮“确认无误”或“撤销核对”；对局码字段另有“这张地图最近的对局码”快捷选项（点选即填入，仍可手动输入），识别不出或需修正时无需从头输入
- “识别详情”折叠区含处理尝试、对局环境识别结果和“查看原始识别数据”。

**芯片状态**：一致、待确认（`warning`）、已核对 / 已校正（`success-surface`）、无法识别（`danger`）。
**空状态**：“暂无 OCR 结果，可逐项填写截图中的实际值。”
**选项文案**：通关标记 已完成 / 未完成；地图版本 标准版 / 经典版；模式 “常规（随机事件）”；难度 简单 / 一般 / 困难 / 专家 / 传奇 / 地狱。

**无障碍**：芯片 `aria-expanded`、`aria-controls`，`aria-label` “{标签}：{值}，{状态}”；各控件 `aria-label` “截图中的{标签}…”；图标 `aria-hidden`；`disabled` 时全部输入和按钮禁用。

**建议稿（2026-10）**：已核对的芯片只用一个 ✓（“已核对”靠成功色和标签区分，不叠两个勾）；删除提示“核对后的值会随审核决定保存。”；对局码编辑器加入该地图最近对局码的快速选择。
