# EditorialShare

复制链接与（浏览器支持时）系统分享的按钮组。逻辑来自 `useEditorialShare`。

**属性**：`url`、`title`。

**结构**：两个次要描边按钮（`hit-target-lg`）：
- 「复制链接」+ 链接图标；复制成功后变为「已复制」+ 勾图标
- 「分享」+ 分享图标，仅在支持原生分享时出现

**状态**：默认、已复制、不支持原生分享（隐藏「分享」）。

**无障碍**：原生按钮，文字即访问名称；复制成功反馈没有 aria-live（源码未处理）。

**Token**：`hit-target-lg`、--space-2。
