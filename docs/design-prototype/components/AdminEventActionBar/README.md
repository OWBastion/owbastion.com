事件列表底部的吸底操作条。合并原 `AdminEventSelectionBar`（批量操作选中项）和 `AdminEventDraftBar`（未保存草稿的保存或放弃）。两者都是列表底部的上下文操作条，同一时间只需要一条。

**状态**
- 只有选中项：左侧“已选 N 项”，批量控件（设为状态、移到版本、设事件组、权重＝ / ＋ / ×加数值与“应用”），右侧“取消选择”。
- 只有草稿：左侧“N 项未保存的修改”加分类摘要（权重 2 项 · 状态 1 项），右侧“放弃”“保存全部”。边框用 `accent`，底为 `accent` 的 9% 与 `surface` 混合，`elevation-2`。
- 两者同时存在：批量控件在左，右侧显示“N 项未保存”加“放弃”“保存全部”；此时不再显示“取消选择”（取消选择在批量控件里的清除操作），避免同一条上有两组收尾按钮。
- 都没有：不渲染。

**规则**：吸底，`role="status"`；批量控件最小高度 `control-sm`；所有批量操作只作用于选中项，未保存草稿只由“保存全部”提交。
