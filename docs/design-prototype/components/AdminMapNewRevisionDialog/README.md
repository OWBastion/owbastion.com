# AdminMapNewRevisionDialog

新建地图修订的对话框：选择修订类型，填写游戏版本和备注。新修订从“准备中”开始。

**结构**
- 标题“新建修订”，说明“新修订从「准备中」开始，不影响玩家当前的进度。”
- 修订类型三选一：限时 / 活动版本、地图重置 / 重做、经典版，各带一句说明
- 游戏版本（必填）和备注（占位“可选，例如：2026 周年庆活动”）
- 底部“创建修订”和“取消”

**状态**
- 每次打开默认选中“地图重置 / 重做”，游戏版本取当前版本，备注清空
- 游戏版本去空格后为空时“创建修订”禁用
- `saving` 时输入禁用、创建按钮 loading、取消禁用、对话框不可关闭

**Token**：选项卡 1.5px 边框，选中为 `accent` 边框加 `accent-surface` 底；`radius-control`。

**无障碍**
- 类型选项 `role="radiogroup"`、`aria-label="修订类型"`，选项 `role="radio"` 加 `aria-checked`
- 标题和描述由 AdminResponsiveDialog 提供；源码未见方向键切换
