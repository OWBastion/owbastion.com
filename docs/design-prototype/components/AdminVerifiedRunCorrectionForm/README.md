# AdminVerifiedRunCorrectionForm

更正已核验通关记录事实字段的表单，附可选更正理由。

**结构**
- 顶部 `warning` 提示：“更正会保留来源提交和接受记录，重新计算当前经验与地图档案，并保存更正前后的事实快照。”之后可有外部错误和校验提示。
- 字段网格（自适应，最小 17rem）：地图、玩法修订（均为选择器，显示名称，不显示程序 ID）、难度（简单 / 一般 / 困难 / 专家 / 传奇 / 地狱）、游戏版本、对局码、通关用时（秒）、死亡次数、跳过次数。死亡和跳过的提示均为“留空表示未知”。
- “事件次数”按事件名逐行列出数字（建议稿，取代 JSON 文本域；界面不出现事件键）；“更正理由和依据（可选）”文本域（3 行，占位“核对依据和本次修正内容”）。
- 右对齐操作行：“保存更正”（提交）和“取消”。

**状态**
- 保存中：全部输入和取消禁用，保存按钮 `loading`，表单 `aria-busy`。
- 校验文案：“请选择地图和玩法修订”“游戏版本不能为空”“事件次数必须是非负整数”“通关用时必须是大于零的整数”“死亡次数必须是非负整数”“跳过次数必须是非负整数”，默认“更正内容无效”。
- 空的死亡、跳过提交为 `null`；理由为空则不带该字段。

**无障碍**：每个字段有 `UFormField` 标签，必填输入带 `required`。

**建议稿（2026-10）**：地图、玩法修订、难度均为带右侧箭头的选择框（文字左对齐，箭头靠右，与输入框同高）；统一称“对局码”，不用“通关码”。
