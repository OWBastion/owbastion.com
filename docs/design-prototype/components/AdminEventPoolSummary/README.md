# AdminEventPoolSummary

随机事件候选池概览：候选池里的已实装事件数、权重合计，并可按版本挂起或恢复。

**结构**
- 左侧两个事实：“N 个已实装事件在候选池”“权重合计”（数值 `type-card-title` 尺寸、`text` 色，权重最多两位小数）
- 右对齐“版本可用性”列表：每个版本一个胶囊按钮，含状态圆点和版本号
- 独立模式的版本旁显示链接“仅 {模式}”，指向 /admin/modes

**状态**
- 可用版本圆点为 `success`；挂起版本圆点 `warning`、文字 `quiet` 加删除线，并显示“已挂起”
- 任一保存中时所有版本按钮禁用
- 容器小于 40rem 时版本列表左对齐

**Token**：`surface-card`、`pressable-soft`、`success`、`warning`、`line`、`quiet`、`radius-pill`、`control-sm`。

**无障碍**
- `section` 的 `aria-label` 为“候选池”，列表为“版本可用性”
- 版本按钮 `aria-pressed`（可用为 true），`aria-label` 为“挂起版本 / 恢复版本 {v}”
- 链接 `aria-label` 为“{v} 属于独立模式 {mode}”，圆点 `aria-hidden`


**版本芯片布局**（建议稿，预览已按此绘制，代码尚未实现）
- 状态和独立模式不再以文字接在芯片后面：每个版本是一个整体芯片，左侧为圆点加版本号（切换按钮），右侧用分隔线隔出的标签段。
- 已挂起：整体弱化，右侧显示警告色「已挂起」标签；去掉删除线。属于独立模式：右侧显示「仅 {模式}」链接段。
- 切换按钮与链接并列而非嵌套，保持各自独立的可聚焦目标。
