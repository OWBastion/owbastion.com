# AdminPlayerDetail

单个玩家的详情视图：头部操作、告警，以及“称号 / 动态 / 账号”三个分区标签。

**头部**：玩家名 `h2` 加 “#玩家ID”，摘要“N 个称号 · N 个 QQ 绑定 · N 次已核验通关”；操作是主按钮“发放称号”和“更多操作”菜单（查看通关记录、编辑战网 ID、编辑佩戴选择、签发 Passkey 恢复链接，以及解除封禁或封禁玩家）。容器宽于 40rem 时隐藏“返回列表”。

**告警（按条件出现）**
- 封禁：error “该玩家已被封禁”，动作“解除封禁”。
- 需佩戴：warning “需要选择佩戴称号”，动作“选择佩戴称号”。
- 待审：info “有 N 条提交等待审核”，动作“去审核”。

**分区**：`role="tablist"`（“玩家详情分区”），底部 2px `accent` 滑块。动态是时间线（标题、详情、`StatusBadge`、时间）；账号含战网 ID、“QQ 绑定”（“解除绑定”）、“Passkey 恢复”（“签发恢复链接”）。

**状态**：`loading` 时发放、更多、解除绑定、签发恢复均禁用；封禁时签发恢复禁用。空文案：“还没有动态。”“没有 QQ 绑定。”

**无障碍**：tablist、tab、tabpanel 用 `aria-selected`、`aria-controls`、`aria-labelledby` 完整关联；“更多操作”按钮有 `aria-label`。
