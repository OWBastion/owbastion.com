「我的成就」总览：通用成就目录（含已获得、佩戴状态）、地图成就进度、其他地图称号，以及右侧「最近获得」。

**结构**
- 「通用成就」：右侧「已佩戴 {n} / 10」与帮助按钮（说明「佩戴的称号会在游戏内可用。修改会在后续游戏版本同步后生效。」）；「已获得 {earned} / {total}」；分类卡片内每项含图标、称号名、条件、进度（「已完成 x / y」＋地图 ✓/○）、状态「未开放」「即将结束」、右上「已获得」图标、佩戴按钮「佩戴」/「取消佩戴」。
- 「地图成就」：内嵌 `MapMasteryCard variant="progress"`（显示目标，不显示精通数据）。
- 「其他地图称号」：按地图名分组，非默认玩法版本的显示「历史版本」徽标。
- 侧栏「最近获得」：最近 3 个称号，含图标、名称、日期。

**状态**
- 已获得卡片边框与底色混入 `success`。
- 需恢复（全局称号多于 10 个且已佩戴为 0）：警告提示「需要选择佩戴称号」。
- 佩戴按钮在保存中，或未佩戴且已佩戴满 10 个时禁用。
- 空态：「暂无记录」；侧栏「暂无称号」。

**无障碍**
- 各 section `aria-labelledby`；侧栏 `aria-label="最近获得"`；按钮 `aria-label="佩戴 {label}"`；已获得图标 `role="img"`。

**建议稿（2026-10）**：绿色卡片底色只表示“已获得”，不再叠加绿色对勾（对勾容易被理解成“已佩戴”）。“已佩戴”用文字徽标贴在称号名下，按钮为“取消佩戴”；未佩戴的已获得称号按钮为“佩戴”。进度清单里的对勾仍表示该地图已完成，且只出现在清单内。
