# AdminMapPromoteDialog

确认把某个修订设为正式版；已有正式版时，同时选择原正式版的去向。

**结构**
- 标题“把「{修订名}」设为正式版？”，说明同一时间只有一个正式版，不会复制或清除任何玩家进度
- 有原正式版时显示“原正式版「名称 · 游戏版本」改为：”及两个选项：保留为可选版本、归档为历史版本
- 底部“确认设为正式版”和“取消”

**状态**
- 每次打开默认选“保留为可选版本”（玩家仍可选择它游玩，适合限时版本并行）
- “归档为历史版本”：不再开放，已有记录全部保留
- 没有原正式版时没有选项区；`saving` 时确认 loading、取消禁用、不可关闭

**Token**：同新建修订对话框：1.5px 选项边框，选中 `accent` 与 `accent-surface`。

**无障碍**
- 选项区 `role="radiogroup"`，`aria-label` 为“原正式版「名称」改为”，选项 `role="radio"` 加 `aria-checked`
- 焦点管理由 AdminResponsiveDialog 提供（本文件未确认）
