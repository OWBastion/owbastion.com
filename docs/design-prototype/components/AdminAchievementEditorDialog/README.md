# AdminAchievementEditorDialog

编辑称号目录项、通用挑战或地图挑战的对话框，字段随条目类型变化。

**结构**
- 标题：目录项“编辑称号目录”，其余“编辑规则”；说明为称号名或挑战名
- 目录项字段：称号标签、图标键、系列、范围、展示方式、颜色、生命周期，以及“公开显示”复选框
- 挑战字段：完成条件、截图规则、提交方式、状态；通用挑战另有完成规则、统计范围、适用范围、地图版本、开始与结束时间
- 折叠区“更多设置”：计划下线版本、游戏版本、自定义图标与上传、展示分类；有 retiredVersion 时默认展开
- 底部“保存目录”或“保存规则”，以及“取消”

**状态**
- `saving` 时全部字段和取消禁用；`item` 为空时不渲染表单
- 上传中文件选择禁用、上传按钮 loading；没选文件时上传按钮禁用
- 图标提示：“PNG、JPG 或 WebP，最大 512 KB。”

**Token**：类 `editor-field`、`editor-control`、`admin-achievement-icon-preview`；`muted`、`line`。

**无障碍**
- 原生 form 与必填字段
- `details/summary` 折叠，图标预览 alt 为“当前成就图标”


**统一布局**（建议稿，预览已按此绘制，代码尚未实现）
- 新建与编辑使用同一顺序：基本信息（名称、完成条件）→ 状态与完成规则 → 时间（开始、结束、计划下线版本）→ 更多设置（截图规则、提交方式、适用范围、游戏版本、图标、展示分类）。
- 同一行的字段顶端对齐，不因相邻字段带说明文字而被拉高；选择框高度与输入框同为 `control-md`。
