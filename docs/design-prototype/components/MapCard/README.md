地图目录卡，所有宽度同一结构：封面、标题行、评分摘要、统计、标签。整张卡是一个按钮。

**结构**
- 封面 16:9（窄于 24rem 时 2:1），无封面时用 `accent-surface` 底加两位字母索引。
- 标题行：名称 `type-card-title` 在左，版本 `type-caption` `quiet` 在右。
- 统计最多 3 项，上方 1px `line`；缺失写“暂无记录”（`quiet`、500）。
- 标签用中性胶囊。

**规则**
- 整张卡带 `aria-label`（“查看<地图>详情”）；悬停和聚焦 `line-strong` 加 `elevation-1`，按压 `pressable-soft`，不上浮。
- 没有媒体或统计的卡只去掉没有数据的部分，不改变其他结构。第四项统计放进详情。
