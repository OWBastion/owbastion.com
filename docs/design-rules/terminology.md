# Portal 术语表

本术语表是 `apps/portal` 及其管理后台文案的唯一中文术语来源。新增或修改
任何文案前，必须先查本表；接口字段、数据库字段和 Bastion 消费的英文枚举值
保持不变，不把中文术语反向写入这些契约。

## 基本概念

| 术语 | 用法 |
| --- | --- |
| 称号 | `title_catalog` 中的实际称号名称，例如“开拓者”“征服者”“主宰”。 |
| 地图称号 | 作用范围限定为单张地图的称号。 |
| 地图称号规则 | 权威规则实体，定义称号、完成条件、截图规则、展示方式、称号槽位和生命周期。 |
| 称号槽位 | 地图称号在地图奖励中的分类；不是称号名称，也不是游戏难度。 |
| 地图例外 | 某张地图对权威规则的启用、停用或字段覆盖。 |

## 标准地图称号

| 代码 | 称号名称 | 中文槽位术语 | 当前完成条件 |
| --- | --- | --- | --- |
| `PIONEER` / `pioneer` | 开拓者 | 开拓者槽位 | 在新地图内测或公测中完成对应地图地狱难度，由群内审核发放。 |
| `CONQUEROR` / `conqueror` | 征服者 | 征服者槽位 | 通关对应地图传奇难度。 |
| `DOMINATOR` / `dominator` | 主宰 | 主宰槽位 | 通关对应地图地狱难度。 |

“先锋”和“支配者”只作为历史代码语义或外部英文枚举的解释，不作为 Portal
称号名称或槽位文案单独使用；分别统一写为“开拓者”和“主宰”。

## 展示方式

| 枚举值 | Portal 文案 | 含义 |
| --- | --- | --- |
| `fixed` | 固定称号 | 直接使用称号名称。 |
| `map_pioneer` | 地图名 + 开拓者 | 使用地图名（或地图专用前缀）与“开拓者”组合展示。 |
| `map_name_suffix` | 地图名 + 后缀称号 | 将称号名称作为地图名后的后缀展示。 |

“地图先锋”不再作为展示方式文案使用；“段位”不用于描述地图称号槽位。

## 修改前检查

1. 先查本表，确认是称号名称、称号槽位、展示方式还是产品流程术语。
2. 复用表中的中文；若现有数据与本表冲突，优先保留数据中的 `titleKey` 和
   枚举值，在展示层统一中文。
3. 若需要新增术语或改变标准称号名称，先更新本表及其对应的权威数据，再
   修改页面文案。
