# Portal UI/UX 独立审计 · 2026-08-17

本次审计只读当前 `apps/portal` 实现，对照：

- 设计宪章与支柱：`DESIGN.md`、视觉 / 布局 / 组件 / 交互 / 动效 / 页面范式 / 内容状态 / Portal UI / 文案 / 术语
- Apple Design：Purpose、Agency、Wayfinding、Simplicity、Craft、Feedback、空间一致性、材料层级、按压即时反馈
- Kill AI Slop：先扫描后人工确认；只记录确认过的 slop，不把品牌选择当 slop

**未读取**任何既有 `audit-*` 档案。结论以本轮源码为准。

范围：公开目录、登录绑定、玩家中心、截图提交、管理后台、共享 chrome。Studio 只核对入口与加载壳，不审计第三方编辑器内部。

严重度：

| 级 | 含义 |
| --- | --- |
| P0 | 决策面不可用，或关键操作被组件契约吞掉 |
| P1 | 找路失败、事实说错、状态重复导致误判 |
| P2 | 文案 / 层级 / slop 降低扫描效率 |
| P3 | 单位、断点、密度债务；不挡功能 |

## 1. 总体判断

Portal 已有可用的设计系统：语义 token、`page-shell` 档位、`pressable*`、玻璃顶栏、目录 / 玩家中心 / 上传 / 管理列表范式大体对得上。玩家侧状态词和「核对 / 获得 / 不再发放」大体守住。审核详情的「认领 → 决定 → 证据」是当前最好的决策面。

本轮问题不在「再换一套视觉」，而在三件事：

1. **若干管理决策对话框把内容放进了默认槽**，`AdminResponsiveDialog` 只渲染 `#body` / `#footer`，界面是空的。
2. **页面说一套、导航给另一套**：首页承诺地图却不链地图；「事件」与「随机事件」并存；开发日志不进主导航。
3. **解释层和仪表盘层盖住了内容**：默认副标题、流程说明书、四格统计、完成率环、最近获得称号却套完整手风琴。

装饰性 slop 在品牌层不多（橙色强调、系统字体、玻璃顶栏应保留）。真正的 slop 出现在运营页被做成杂志仪表盘。

### 1.1 故意保留（不是 slop）

- `--accent` 橙色、系统 / SF / PingFang 栈、品牌字标 `O`
- 顶栏 `glass` + `scroll-edge`（规范允许的材料；`prefers-reduced-transparency` 已固化）
- 管理后台使用 OCR / 审核内部词（术语表允许）
- 「不再发放」作为玩家侧既定产品语义
- 管理事件表的 bounded + 虚拟滚动（页面写了操作理由）
- 证据图在提交详情用 `width: 100%; height: auto`

### 1.2 扫描误报（已排除）

Kill-ai-slop 扫描 249 击，多数是链接下划线、kicker token 定义、管理端等宽 ID、博客历史 emoji。下列不作为 slop：`main.css` 的 scroll-edge 渐变（软分隔）、等宽邀请码 / 坐标、管理 OCR 列名。

## 8. 管理后台

共享原语判断：`AdminWorkspace` + `AdminDataTable` 默认文档流正确；无页面级 `position: fixed` 决策条。`AdminResponsiveDialog` **只挂载具名槽** `#body` / `#footer`。

### 8.1 P0 — 对话框空壳 + 分页失踪

`pages/admin/annotations/index.vue`（约 236–264）和 `pages/admin/datasets/index.vue`（约 128–162）把详情放进**默认槽**。打开后只有标题 / 描述，提案内容、编辑、直接创建、定稿按钮都不出现。

两页都有 `page` / `total` / `pageSize=20`，**没有 `UPagination`**，第 2 页不可达。

**优化：** 全部改 `#body`；接受 / 拒绝 / 保存审定 / 定稿放 `#footer`。每表后加 `UPagination`。标注占位「备注（可选）」改为「备注」。

### 8.2 管理概览 · `/admin`

四格统计（待审核、OCR 队列、活跃玩家、地图目录）。前两格都进 `/admin/reviews`。后两格不改变下一步。`::before` 7px 圆点是发光状态点变体。错误用裸 `<p>` 不是 `UAlert`。

**优化：** 工作区 count 用「待核对 N」；删四格或只留可跳转的待核对。队列行展示与审核表相同的主事实（识别地图 + 状态）。文案与列表对齐：「等待核对」，不要另造「待审核」指标名（管理导航「审核」可保留）。

### 8.3 审核列表 / 详情

列表范式正确：文档流、筛选、行进详情。移动端详情列过多（置信度 / OCRKit / 时间可进展开）。

详情是本轮最佳决策面：主操作「通过」、次要「要求重提」、危险「驳回」且理由非必填；决定条 sticky 不 fixed。

可减：kicker「申请目标 / 审核决定 / 核对 / 识别」；玩家名在 meta 与提交信息重复。空状态「提交记录可能已不存在或链接无效」过删除测试。

### 8.4 绑定 · `/admin/bindings`

Tab + 表 + 对话框大体正确。

| 级 | 发现 | 优化设计 |
| --- | --- | --- |
| P1 | count 永远是 `claims.length`，切到邀请码 / 当前绑定仍显示申请条数 | count 跟当前 tab |
| P1 | 「将撤销的 binding 数量」「将失效的 Session 数量」 | 「将解除的绑定」「将退出的登录」 |
| P2 | 行内拒绝无确认；冲突批准有确认 | 拒绝同样确认；理由仍可选 |
| P2 | 无 `mobile-columns`，移动端倒出全部桌面列 | 主列：玩家 + 状态；其余进详情 |

邀请创建里的「管理员授权」chip 和内嵌卡可拍平。

### 8.5 玩家列表 / 详情

列表是管理表范本（搜索 + 一筛 + `mobile-row-link`）。

详情顶上三格（有效称号 / 最近提交 / QQ 绑定）复述下方分区。返回是矮文本链。解绑 `variant="link"`。称号表 empty 与额外 `UEmpty` 重复。

**优化：** 删三格；返回与解绑用 `UButton`；只留一处空态。

### 8.6 地图列表 / 编辑器

列表缺 `mobile-row-link`，移动端要点溢出菜单才进编辑器。编辑器 master/detail 与 sticky 保存合法。页头「返回」和「重置 / 重做」并列为两个可见操作。加载只有 count「读取中…」。

**优化：** 行主体进 `/admin/maps/:id`。主操作「保存」；重置放修订栏次要。补 master + 表单骨架。

### 8.7 成就与称号 · `/admin/achievements`

`/admin/map-titles`、`/admin/grants` 仅为跳转，可保留。

状态筛在「通用」与「目录」间共享，切 tab 会留下对方没有的值。行操作是自定义 icon `button`，不是 `UButton sm`。目录行重复「无挑战，可单独授予」。地图 tab eyebrow「地图成就」+ 说明段「规则是地图称号的唯一编辑入口…」过删除测试。

**优化：** 每 tab 独立筛选；行操作用带标签或保证 44px 的 `UButton`；删 eyebrow 与说明段。

### 8.8 历史称号 · `/admin/titles`

四格指标 + 图标是确认 slop（数量已在持有者列表）。eyebrow「历史持有者」。批量确认对话框里的事实小卡是卡套卡。

**优化：** 删 `AdminTitleMigrationMetrics`；对话框用 `dl`。

### 8.9 事件 · `/admin/events`

Bounded 虚拟滚动有理由。移动端倒出 11 个字段。导入说明「低频维护操作…」过删除测试。概率七个只读输入像表单。

**优化：** 移动主列：名称 + 类别 + 状态。概率改紧凑 `dl`。

### 8.10 渠道 · `/admin/channels`

行内开关无 `aria-label`；保存中无 loading。群名约束说明保留。

### 8.11 通关记录 / 玩家评价

通关：默认露出通关码即可，ID / 日期进抽屉。成功 `UAlert` 应改为 toast。确认时页内作废按钮仍可点。详情四层 `surface-card` 可拍成事实表 + 冲突表。

评价：对话框 description 是 onboarding；「确认隐藏评论？」与按钮文案重复。详情 2×3 事实小卡改为一张 `dl`。审计行不要裸 `operation` 枚举。

### 8.12 Studio · `/studio`

独立同源入口，无 Portal 再包一层导航。全屏 loading 的 `position: fixed` 是壳，不是功能码头。保持。

## 10. Apple Design 对照（本轮只抓会改交互的）

| 原则 | 现状 | 设计方向 |
| --- | --- | --- |
| Wayfinding | 首页无地图；博客不进顶栏；事件双名；地图 overlay 不进历史 | 导航 = 页面名 = 入口卡 |
| Purpose | 成就页 / 管理概览用环和四格代替下一步 | 扫描 → 定位 → 判断 → 行动 |
| Simplicity | 提交详情状态三重奏；上传页流程说明书 | 徽标 + 一个下一步 |
| Feedback | 顶栏退出无 loading；标注对话框空 | 按压已有；补操作中状态；先修空对话框 |
| Grouping | `/me` 用全集组件展示 3 条最近称号 | 预览用行，全集用手风琴 |
| Materials | 顶栏玻璃正确；不要再叠一层轻玻璃 | 保持共享 `glass*` |
| Type | 局部 tracking / 自建字号 | 只用 `type-*` |
| Reduced motion | 顶栏、overlay、press 大体遵守 | 不要再写组件级 transform |

不为本产品补弹簧手势。规范禁止在普通流程上做自定义 drag / rubber-band。
